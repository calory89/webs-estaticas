How the scores work

Every project gets ten scores from 0 to 100: price, value per m², location, beach, facilities, delivery, developer, space, visitor interest and listing detail. The grade of each project is the plain average of the ten. Price, value, space and visitor interest compare a project with the other 99 in the same ranking. Beach uses the straight-line distance to the coastline on OpenStreetMap, and facilities counts what the developer's public listing shows (pool, gym, spa, coworking, security and so on). Those two use the same scale in every destination, so you can compare Bali with Batumi.

None of this is advice to buy. Prices and dates come from public listings and change. Ask the developer before you decide, and check the facilities are built, not only drawn.
