Kolaboro / Browser extension

Check an off-plan project from the page you are on

A small Chrome extension for buyers. On any developer or agent page, one click sends that address to Kolaboro's free desk review, and a six-point checklist shows what the page should be telling you before you pay a deposit.

Download for ChromeHow to install

Version 1.0.0. Free. No account. Chrome Web Store listing coming soon.

What it does

Three things, nothing running in the background

Check this project

Opens kolaboro.com/check in a new tab with the page address filled in, so the free desk review starts straight away.

A six-point checklist

Tick what you can see on the page: permit number, deposit protection, construction progress, plans, track record, and no guaranteed returns. Each gap is a question for the seller.

Right-click any link

"Check with Kolaboro" appears when you right-click a page or a link, handy on listing portals where each project is a link.

Screenshots

What you see when you click the icon

The checklist is the same six points we use on every project in the database. Your ticks stay in your browser, saved per page.

Install

Install it in Chrome in four steps

Until the Chrome Web Store listing is live, you load it yourself. It takes about a minute.

  1. Download and unzip

    Download the zip and unzip it. You get a folder called kolaboro-extension.

  2. Open extensions

    Type chrome://extensions in the address bar and press Enter.

  3. Turn on Developer mode

    Use the Developer mode switch in the top right corner of that page.

  4. Load unpacked

    Click Load unpacked and pick the kolaboro-extension folder. Pin the Kolaboro icon from the puzzle menu.

Coming soonA Chrome Web Store listing is on the way. Until then Chrome may show a reminder that a developer mode extension is installed; that is normal for extensions loaded this way.

Privacy

No tracking. It only sends the address you choose to check.

The extension has no analytics, reads nothing from the pages you visit and runs no code inside them. Nothing leaves your browser until you press Check this project or pick Check with Kolaboro, and then only that one address goes to kolaboro.com.

activeTab
Lets the popup read the address of the tab you are on, only at the moment you click the icon. No access to other tabs or your history.
contextMenus
Adds the "Check with Kolaboro" item to the right-click menu.
No host permissions
It cannot read or change any website, and there is no content script.
Checklist ticks
Stored only in your browser, inside the extension. Removing the extension deletes them.

Once kolaboro.com opens, the normal site privacy policy applies. Read the full source before you install: manifest.json, background.js, popup.html, popup.js.
