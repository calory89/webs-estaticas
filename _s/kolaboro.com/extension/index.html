Kolaboro / Browser extension

Check an off-plan project from the page you are on

A small Chrome extension for buyers. On property portals it quietly shows Kolaboro's public record when a listing is a project we track. On any developer or agent page, one click sends that address to Kolaboro's free desk review, and a six-point checklist shows what the page should be telling you before you pay a deposit.

Download for ChromeHow to install

Version 1.1.0 (3 Nov 2026): adds the overlay on property portals. Free. No account. Chrome Web Store listing coming soon.

What it does

Four things, and nothing sent without a reason

Check this project

Opens kolaboro.com/check in a new tab with the page address filled in, so the free desk review starts straight away.

A six-point checklist

Tick what you can see on the page: permit number, deposit protection, construction progress, plans, track record, and no guaranteed returns. Each gap is a question for the seller.

Right-click any link

"Check with Kolaboro" appears when you right-click a page or a link, handy on listing portals where each project is a link.

Our record on portals

On Property Finder, Bayut, Rumah123, FazWaz and other portals, a small card shows Kolaboro's public record when the listing is a project we track. How it works.

New in 1.1.0

Our record, on the listing you are looking at

Open a listing on a property portal. If it is one of the projects Kolaboro tracks, a small card appears in the corner: the project's anonymous id, how many of the six buyer checks are public, any risk report, and a link to the full record. If it is not tracked, nothing appears.

It matches in two ways: by the listing's address, when that exact page is one of our research sources, or by the project's name in the listing title, only within the portal's own country. A name match says so on the card, so you can confirm it is the same project.

Coverage today: 190 projects by listing address and 771 by project name, of 891 tracked.

Portals: Property Finder (UAE, Bahrain, Egypt, Qatar, Saudi Arabia), Bayut, Rumah123, FazWaz, Dot Property, Thailand-Property, Rumavi, Realting, Emlak Platform, Pincali, EdgeProp, PropertyGuru Malaysia, idealista (Spain, Portugal) and Apartments.com.au. These are the portals that appear in our research sources, plus the main portals of our largest markets.

How it stays privateThe page address and title never leave your browser. The extension hashes them (SHA-256) on your device and sends only the first 4 characters of each hash, so our server answers with every tracked key in those buckets and the match is made on your device. Same idea as a password range check. No cookies, no identifiers, nothing stored, and it runs only on the portals above.

Install

Install it in Chrome in four steps

Until the Chrome Web Store listing is live, you load it yourself. It takes about a minute.

  1. Download and unzip

    Download the zip and unzip it. You get a folder called kolaboro-extension.

  2. Open extensions

    Type chrome://extensions in the address bar and press Enter.

  3. Turn on Developer mode

    Use the Developer mode switch in the top right corner of that page.

  4. Load unpacked

    Click Load unpacked and pick the kolaboro-extension folder. Pin the Kolaboro icon from the puzzle menu.

Privacy

No tracking. The overlay sends hash fragments, not addresses.

The extension has no analytics. It runs code only on the property portals listed above, to look for a tracked project, and there it sends only 4-character hash prefixes, never the address or the title. Everywhere else it reads nothing. The address of a page goes to kolaboro.com only when you press Check this project or pick Check with Kolaboro.

activeTab
Lets the popup read the address of the tab you are on, only at the moment you click the icon. No access to other tabs or your history.
contextMenus
Adds the "Check with Kolaboro" item to the right-click menu.
Property portals only
A content script runs on the portals listed above, and nowhere else. It reads the listing's address, its main heading and the page title, hashes them on your device and adds the card when there is a match. It changes nothing else on the page. No other host permissions.
Checklist ticks
Stored only in your browser, inside the extension. Removing the extension deletes them.

Once kolaboro.com opens, the normal site privacy policy applies. Read the full source before you install: manifest.json, background.js, popup.html, popup.js, content.js.
