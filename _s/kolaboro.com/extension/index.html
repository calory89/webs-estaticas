Kolaboro / Browser extension

Kolaboro X-ray, on the listing you are looking at

A free extension for Chrome and Edge. On property portals it shows what our records say about the project in front of you, with a link to its full public page. On any developer site, one click does the same. Then run a live X-ray of public sources without leaving the page.

Download for Chrome and EdgeHow to install

What it does

  • Recognises the project

    On six property portals the panel appears when the listing is a project or developer we track: name, developer, place, stage at our last check, the handover date the developer promised, and when we last checked. Projects we have not reviewed yet show facts only, no score.

  • Works on developer sites

    Click the Kolaboro icon on a developer's or agent's page. If the website belongs to a developer we track, you see the project or the list of its projects we follow, each linking to its named page.

  • Runs the X-ray

    Registers, domain and certificate history, the Internet Archive, hosting, location and satellite, reused images, market base rates and buyer law. Each check says Found, Not found or Not published, and the result is sealed with a fingerprint.

On a listing we track you see the full panel. On another listing page you see a small "Kolaboro X-ray" button that opens it. On search and home pages nothing appears.

Gmail on the web

When an email you open mentions a payment or bank details, a small panel shows: whether the sender's address is the developer website we hold or a lookalike, a free email account, Reply-To, mailed-by and signed-by on another domain (open Gmail's details arrow to include them), wording used in payment-diversion emails, and the sender domain's age. It ends with the same advice every time: call the developer on a number from its official website before paying.

The email's text is read on your device and never sent. Only the sender's domain goes to kolaboro.com, for its public DNS and registration date. The full check with all headers is at /tools/payment-email-check/.

Everywhere else

Click the icon. The extension reads the address and title of that tab at that moment, and only then. It works on developer sites, agents' pages and smaller portals.

How a match is made, in order: the exact page address, the website's domain, the project name on the page (only within the portal's own country), then the developer name. The panel says which one matched, so you can confirm it is the same project.

Interface in English, Español, Deutsch, Français, Nederlands, Русский, 中文 and العربية, following your browser language.

Install it in about a minute

Until the store listings are live, you load the extension yourself. Chrome and Edge use the same file.

  1. Download and unzip

    Download the zip and unzip it. You get a folder called kolaboro-x-ray.

  2. Open the extensions page

    In Chrome type chrome://extensions in the address bar. In Edge type edge://extensions.

  3. Turn on Developer mode

    The switch is in the top right corner in Chrome, and in the left column in Edge.

  4. Load unpacked

    Click Load unpacked and pick the kolaboro-x-ray folder. Pin the Kolaboro icon from the puzzle menu so it is one click away.

Updating from version 1Remove the old "Kolaboro: check off-plan projects" extension first, then load the new folder. Chrome may remind you that a developer mode extension is installed; that is normal for extensions loaded this way.

Privacy statement

No tracking. The automatic lookup sends hash fragments, not addresses. The page address goes to Kolaboro only when you press Run the X-ray.

The lookup
On the six portals, and in the popup when you click the icon, the extension takes the page address, its domain, the main heading and the title, and hashes them on your device (SHA-256). It sends only the first 4 characters of each hash to kolaboro.com/api/x/j/xr. Our server answers with every record in those buckets and the match is made on your device, so we cannot tell which page you were on.
The X-ray
Only when you press Run the X-ray, the page address is sent to kolaboro.com, which checks it against public sources. The result (the address and what the sources returned) is kept as a sealed record so its link works. It holds no name, account, IP address or other identifier. Your IP address is used only for a rate-limit counter that expires within an hour.
Gmail
On mail.google.com the extension reads the open email's sender, text and, if you open them, the Reply-To, mailed-by and signed-by details, only to decide whether it mentions a payment and to run the checks on your device. The text, addresses and account numbers are never sent. The sender's domain name alone (for example example.com) is sent to kolaboro.com/api/x/fraud/domain to read its public DNS and registration date, and the public list of developer websites comes from kolaboro.com/api/x/fraud/domains. It never reads the inbox list, contacts or attachments and never sends, deletes or changes email.
Permissions
activeTab: read the address and title of the current tab when you click the icon, and at no other time. Host access only to the six portals listed above, to show the panel there, and to mail.google.com for the payment email check. No access to your history, bookmarks, other tabs or other sites.
What is stored
Nothing. The extension has no storage permission, no cookies, no analytics and no identifiers. Removing it removes everything.
Code
All code is in the zip, not minified, with no code loaded from elsewhere. It only fetches data from kolaboro.com.

Once kolaboro.com opens in a tab, the site privacy policy applies. Questions or corrections: corrections.
