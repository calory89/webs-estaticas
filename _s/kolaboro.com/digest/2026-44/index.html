How this digest is built

Data
Only the public files under /data/ (projects, promises, register checks, stalled sites) and their git history: for each day, the last published copy of that day. The week is compared from the last copy before Monday to the last copy of the week. Our stored history starts with the first copy of 2026-10-28; changes are counted from that copy.
Anonymous
Projects appear by id only, as everywhere on Kolaboro.
Intro paragraph

Schedule
Rebuilt every Monday for the week just ended, and on demand; a week shown as "to date" is rebuilt until it is complete. Data: /data/digest.json, RSS: /digest/feed.xml, heatmap of the last 7 and 30 days: /changes/.
