Freshness

Target = twice the run interval of the workflow that writes the file when it runs daily or more often, the interval plus 2 days when it runs weekly or monthly, plus 1 day when the file states only a date (counted from 00:00 UTC). Age = now minus the timestamp the file itself states (or, without one, the time of the last commit that published it). No target for files written by hand, on demand or after events. The Parquet files also count as fresh while they were built from the current bali-cases.json.

Monitors can poll /api/x/data/freshness: it re-reads each file's own timestamp from the first 64 KB of the live file at request time (cached 5 minutes), so a late file shows up within minutes, not at the next catalog run. It answers HTTP 200 with "late": [...]; add ?strict=1 to get HTTP 503 when any dataset is late.

Method and limits

Bytes and SHA-256 are of the exact bytes https://kolaboro.com/data/ served to the job. A tile set has one SHA-256 over the sorted "sha256 path" lines of its files.

Each JSON file is validated against its JSON Schema (2020-12) in /data/schemas/kolaboro-data.schema.json. The contracts were written from the files as published on 5 Nov 2026: every top-level key is required with its type, items of top-level lists and maps must keep the keys every item had, numbers are "number", deeper optional values may be null. Parquet files are checked against the columns and row count in kolaboro.parquet.json, tiles and screenshots against their binary headers. API answers are validated against the response schemas in /docs/api/openapi.json, which were inferred from live responses.

Limits: a contract checks shape and types, not whether the values are right. The contracts started from the files as they were on 5 Nov 2026, so they describe what was published then and can be too strict when a file legitimately grows a new optional shape; such a failure is shown here, not hidden. Row counts count the main list or map of each file (the unit is named). Descriptions are written by hand from each file's own method text; the numbers are measured.
