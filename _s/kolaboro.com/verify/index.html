Kolaboro / Verify evidence

Check that a photo or document from a Kolaboro report is genuine.

Your browser fingerprints the file locally. If it matches our public timestamp record, you get a proof anchored in Bitcoin that you can check independently.

Live · anchored in Bitcoin

Verify a piece of evidence yourself

Drop any photo or document from a Kolaboro report. Your browser computes its SHA-256 fingerprint; the file never leaves your device. We look the fingerprint up in our public timestamp record and give you the OpenTimestamps proof, which you can check with free, independent tools.

How it works: each fingerprint is submitted to independent OpenTimestamps calendars (run by the OpenTimestamps project and Eternity Wall). They aggregate it into a Bitcoin transaction within hours. After that, nobody, including us, can backdate or alter the evidence without it showing.

For clients and their lawyers

Check a whole case file

In the client portal, "Evidence data" downloads every fingerprint in a case. Drop that file here: your browser recomputes the chain item by item and tells you if anything was changed, removed or reordered.

Check that a project's record was sealed

Our research agent fingerprints every developer page it reads. All fingerprints go into one Merkle root that is written to the public log and timestamped in Bitcoin. Type a project ID: your browser fetches a short proof and recomputes the root itself.

Check that an answer really comes from Kolaboro

Every answer of our open data API and every evidence receipt is signed with our Ed25519 key. The public key is at /.well-known/kolaboro-keys.json. Your browser fetches the answer and checks the signature itself.

Any /api/open address, or an evidence number from a report (for example 27) to get its signed receipt.

Check a dataset you downloaded

Drop a copy of bali-cases.json. Your browser computes its SHA-256 and looks for it in the public log. Every API answer also tells you which dataset it came from, in the x-kolaboro-dataset-sha256 header.

These checks run on kolaboro-verify.js, our open-source checker (MIT). You can run the same code on your own machine.
