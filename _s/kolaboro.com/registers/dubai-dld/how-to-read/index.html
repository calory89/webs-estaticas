How to read the Dubai Land Department project register for an off-plan project

Dubai is one of the few markets where the regulator publishes a project record that a buyer can look up. Every step below comes from the Dubai Land Department’s own pages, read on 27 November 2026.

Step by step

  1. Ask the seller for the DLD project number, not only the marketing name. The DLD procedure lets you search by land number, project number or project name.
  2. Open Project Status Enquiry on dubailand.gov.ae or in the Dubai REST app. DLD lists no fee, no required documents and an immediate result. The same service is offered on WhatsApp at 8004488.
  3. Search by the project number or name and open the matching project. If nothing matches, ask the developer for the registered name and number before you pay anything.
  4. For a second view, open Open Data, Real Estate Data, then the Project tab. Its table lists, among others, Project Number, Developer Number, Developer Name, Start Date, End Date, Project Value, Escrow Account Number, Project Status, Completed (%), Inspection Date, Completion Date, Total Units and Master Project. Searching it needs a captcha.
  5. Compare the Escrow Account Number with the account named in your contract and on every payment request.
  6. Read Project Status and Completed (%) together with Inspection Date: the percentage is only as recent as the last inspection on record.
  7. Look the developer up in the Developer tab of the same page, which lists License Number, License Issue Date and License Expiry Date.

What the fields show

Field (official label)What it tells youUse it for
Project NumberThe project is registered with DLD under this number.Permit or licence number
Project StatusThe regulator’s status. The filter offers Active, Finished, Freezed, Under Reviewing, Conditional Activating, Under Cancellation Notification, Under Cancellation Decision and Cancelled.Permit or licence number
Escrow Account NumberThe escrow account recorded for the project.Deposit protection
Completed (%), Inspection DateProgress as recorded by DLD, and the date of the inspection behind it.Construction progress
Start Date, End Date, Completion DateThe dates held on the project record.Construction progress
Developer Number, Developer NameThe registered developer, which you can follow to its licence data in the Developer tab.Developer track record

What it does not prove

  • That the unit you were offered is in this project, or that the seller may sell it.
  • That the percentage matches the site today: it reflects the last recorded inspection.
  • How much money is in the escrow account, or that a payment made to a broker or a personal account ever reached it.
  • That the plans, finishes or handover date in the brochure are the approved ones.

Red flags

  • The seller cannot give a DLD project number, or the number returns a different project or developer.
  • Project Status is Freezed, Under Cancellation Notification, Under Cancellation Decision or Cancelled.
  • The account in your contract or payment request is not the Escrow Account Number on the project record.
  • Completed (%) has not moved and the Inspection Date is old, while the sales material shows fast progress.
  • The developer’s License Expiry Date in the Developer tab has passed.

How it ties to Kolaboro’s six checks

  • Permit or licence number: the DLD project number and Project Status.
  • Deposit protection: the Escrow Account Number.
  • Construction progress: Completed (%) with its Inspection Date.
  • Developer track record: the Developer Number, and the developer’s other projects in the same table.
  • Floor or site plans and no guaranteed returns: not in this register. Check the contract and the advertising.

Sources

  • Dubai Land Department, Project Status Enquiry (description, procedures, fees, channels) (read 27 November 2026)
  • Dubai Land Department, Project Status Enquiry search page (read 27 November 2026)
  • Dubai Land Department, Open Data, Real Estate Data (Project and Developer tabs) (read 27 November 2026)
