What counts as a change

New projects
Project id first appears in the public file.
Page edits
The SHA-256 fingerprint of the developer or listing page text changed.
Price band moves
The advertised price band changed.
Date moves
The advertised completion year, the months the handover date moved, or the months overdue changed.
Register status
A register result appeared or changed, or the number of checks confirmed on an official register changed.
How
For each day we take the last published copy of /data/bali-cases.json on that day and compare it with the previous day's copy. A project counts once per kind and market in a window, however often it changed. Days compared: 2026-10-30, 2026-10-31, 2026-11-01, 2026-11-02, 2026-11-03, 2026-11-04, 2026-11-05. Data: /data/changes.json (CC BY 4.0). The weekly story behind these numbers: weekly digest.
Limits
Our daily history starts on 28 October 2026, so the 30-day window covers fewer days until December. A page edit can be a typo fix or a price change: open the project to see what changed. Built 2026-11-05T07:09:20Z.
