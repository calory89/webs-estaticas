    1. 3 Nov 2026
      • Check our Bitcoin timestamps without trusting us: on the public log, your browser replays the OpenTimestamps proof up to the Bitcoin block and compares it with that block as reported by mempool.space.
      • Copied-render detector: every week each project's images are compared with all other projects' (CLIP, then keypoint matching, so crops and recolours still match). First run: 8,226 images from 797 projects, 0 cross-project reuses after removing portals showing other listings, maps and same-developer pairs. Data and method
      • Two different AI models now read every page. On the fields a buyer acts on they must agree; if they don't, the buyer is told what to check by hand. In today's evaluation they agreed on 131 of 136 critical fields.
      • The AI evaluation now runs again whenever the desk review's code, prompts or test pages change, and the history shows every run, including the ones that failed while we fixed a test that was too strict.
      • If a model returns broken output, the review repairs it or uses the second model, instead of failing.
      • A daily cost ceiling for the website's AI: every call is costed, and the features switch off at the cap. Today's spend is on /status.
      • Founder co-signature: each daily log line can be signed a second time with a passkey on the founder's own device, published and checked in your browser.
      • Case-file PDFs are registered with their SHA-256 when the portal creates them. Anyone can check a PDF on /verify.
      • A second uptime vantage point: GitHub's runners probe the site every hour and prove who they are with a token signed by GitHub (OpenID Connect), with no stored password.
      • Weekly OWASP ZAP security scan. First result: 0 high-risk findings, summary on /status.
      • Decoy credentials (a fake admin key, a fake API key and a decoy path) alert us the moment someone uses them.
      • Data freshness objective: 90% of projects re-read from their source within 7 days, measured per market. Today: 100% of 891.
      • Satellite watch now includes Sentinel-1 radar, which sees through clouds: all 27 watched sites have radar backscatter per period. Satellite watch
      • The AI desk review is protected against manipulated websites: hidden text is removed before the AI reads a page, the page is fenced as data, instructions aimed at AI are detected in eight languages, and an attempt is shown to the buyer as a warning. How it works
      • Daily AI evaluation: every morning the production code reads 17 fictional test pages, including 8 manipulation attempts, and every answer is checked. First run: 17 of 17 cases, 64 of 64 checks. Case by case
      • The public log is now a Merkle tree with a signed checkpoint in the standard signed-note format, inclusion proofs and consistency proofs (RFC 9162). The log page checks in your browser that nothing changed since your last visit. Public log
      • Every daily log line is also recorded in Sigstore Rekor, the public transparency log run by the Linux Foundation, next to the Bitcoin timestamp.
      • Site photos can be signed by the agent's own phone with a passkey (Face ID or fingerprint). The key never leaves the phone, so nobody can put an agent's name on a photo they did not take. Anyone can check the signature from the public receipt. Signed photos
      • Three independent verifiers, in JavaScript, Python and Go, with no dependencies. Every day they check the test vectors and the live log and must agree.
      • Time travel: /api/open/projects/{id}/at/{day} returns a project as published on a past day, from a daily snapshot whose fingerprint is checked against the public log.
      • Weekly backup restore drill: the newest backup is loaded into an empty database and every table and evidence file must match. First run: 14 tables, 3,960 rows, 5 evidence files, all matched.
      • Uptime probes every 5 minutes from outside Cloudflare, errors in visitors' browsers reported to us with a daily digest, and every API answer names the code version that served it.
      • Third-party scripts load with Subresource Integrity, a script allowlist runs in report-only mode, and our security contact is published in /.well-known/security.txt.
      • New Engineering section explaining how Kolaboro is built and checked, with live numbers.
      • Fixed 7 colour-contrast problems found by the daily accessibility check.
      • The desk review now says clearly when a link is not a property project (for example a news site) instead of scoring it.
