La base de données sur plan qui manquait aux acheteurs

Chaque projet suivi par notre agent de recherche, vérifié sur les mêmes six points : ce que publie le promoteur, ce qu’un registre officiel ou une source indépendante confirme, et ce qui est contredit. Mise à jour chaque semaine. Chaque projet a sa propre page, avec son nom et uniquement des faits sourcés. Le promoteur peut y répondre, et nous publions les réponses vérifiées après examen. Les projets à Sumba restent anonymes, car un fondateur y développe un projet (indépendance).

Interrogez la base de données

Posez votre question simplement. L’IA répond uniquement à partir des données publiées et cite les projets sur lesquels repose la réponse.

Quelle part de ce que disent les promoteurs est confirmée

Chacun des six points sur les 1,595 profils approfondis, selon la source la plus solide trouvée.

Ce que publient les promoteurs

Part des projets suivis qui publient chaque élément dont un acheteur prudent a besoin.

Combien des six éléments chaque projet publie

La plupart des projets en publient deux ou trois. En vert : les six, et aucun problème dans les sources publiques.

Comment lire ces données

RegistreConfirmé par une source officielle : cadastre, registre des permis, liste de licences ou registre du commerce.
ConfirméConfirmé par une source indépendante : avis d’un régulateur, décision de justice, document boursier ou grand journal.
Non confirméSeuls le promoteur, ses commerciaux ou les portails d’annonces l’affirment.
ContreditLes sources divergent, ou une source officielle dit autre chose que le promoteur.

Un document publié ne prouve pas qu’il est authentique ; c’est ce que nos agents locaux vérifient sur place et au registre. Les problèmes ne sont repris que de la presse, des tribunaux et des régulateurs. Les promoteurs peuvent répondre sur chaque projet. Données : JSON · API · méthode · corrections.
