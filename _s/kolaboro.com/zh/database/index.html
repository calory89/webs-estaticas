如何解读

官方登记由官方来源证实：土地部门、许可证登记、执照名单或公司登记。
已证实由独立来源证实，例如监管通告、法院记录、证券交易所文件或主流报纸。
未证实只有开发商、其销售代理或房源网站这样说。
被推翻各来源说法不一，或官方来源的说法与开发商不同。

公布了文件并不代表文件是真的；这正是我们的本地代理在现场和登记机构核查的内容。问题只来自新闻、法院和监管机构。开发商可以对任何项目作出回应。数据：JSON · API · 方法 · 更正。
