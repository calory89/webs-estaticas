How to read it

Each case is one fictional page in /open/evals/fixtures/ with checks listed in cases.json: a field of the answer and what it must be. A case passes only when every check passes. The run records the fingerprint (SHA-256) of the prompt and of all fixtures, so a change in either is visible in the history. Raw data: /api/open/evals, signed like every open answer.
