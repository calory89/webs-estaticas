Same rules and the same full round-2 object shape, with these additions:

1. `stage`: "off-plan" (launched or selling, construction not started or just started) or "under construction" (structure going up, not finished). Aim for roughly half of each.
2. More verification per project: test 8 to 14 claims each (permit number valid, escrow account exists, developer company registered, units delivered, completion date, construction stage, price, title for foreigners, rental figures, land ownership, delays). Look actively for registry or independent confirmation; record contradictions.
3. A mix by design: some projects where most checks reach "registry" or "independent", and some where most stays at "developer" or "none". Do not pick only big brands.
4. SAVE AS YOU GO: after finishing each project, rewrite your whole output file as a valid JSON array containing every project finished so far. If your session is interrupted, the work done must already be on disk.
5. Before starting a new project, check it is not in /home/claude/kagent/existing.txt and not already in your own output.
